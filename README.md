# VexaTicket

**Advanced Multi-Guild Discord Ticket Bot + Web Dashboard**

Modern ticket system using **Discord Components V2**, MongoDB, and clean architecture.

## Features
- ✅ Full multi-guild support
- ✅ Components V2 rich panels
- ✅ Ticket open / claim / close / transcript
- ✅ MongoDB persistence
- ✅ Scalable & clean code
- 🔜 Beautiful Next.js dashboard

## Setup
1. `git clone https://github.com/titanxdevz/VexaTicket.git`
2. `cd VexaTicket`
3. Copy `.env.example` → `.env` and fill values
4. `npm install`
5. `npm run dev`

## Tech Stack
- Node.js + TypeScript
- discord.js v14
- Mongoose (MongoDB)
- Components V2
